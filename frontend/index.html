🔑 API Keys

Manage your API keys for programmatic access

📖 How to Use API Keys

  1. Create a Key: Click "Create New API Key" and give it a descriptive name
  2. Save It: ⚠️ Copy and save your key immediately - it's only shown once!
  3. Use It: Include the key in your API requests using the X-API-Key header
  4. Test It: Use the "Test API Key" feature below to verify it works
  5. Revoke: Delete keys you no longer need to keep your account secure
💡 Example Usage: 
curl -X POST http://localhost:8000/api/polls/ \
  -H "X-API-Key: qp_live_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{"title": "My Poll", "options": ["Yes", "No"]}'

💡 Quick Tips:

  • 🔒 Security: Never share your API keys publicly or commit them to version control
  • ⏰ Expiration: Set expiration dates for temporary keys
  • 🏷️ Naming: Use descriptive names to identify where each key is used
  • 🔄 Rotation: Regularly rotate keys for better security
  • 🧪 Testing: Always test new keys before using them in production
